## Các bản đã hoàn thành

### 2.1.0 — Bảo mật và agent runtime

- Tách API token, admin password và session secret.
- Chỉ nhận token qua header; từ chối token trong query string.
- Admin session được ký, cookie `Secure`, `HttpOnly`, `SameSite=Strict`, có CSRF và rate limit.
- CORS đóng mặc định; Vault graph và asset được bảo vệ.
- Docker chạy non-root, read-only filesystem, drop capabilities và có healthcheck.
- Agent tool-calling có allowlist, giới hạn bước/tool calls và không chạy shell.

Commit: `81b1678`.

- Thêm smoke test production chỉ-đọc.

### 2.1.2 — Toàn vẹn Vault và scheduler

- Scheduler có timezone `Asia/Ho_Chi_Minh`, lock, idempotency và giới hạn instance.

- Sửa lỗi dữ liệu mặc định bị thay đổi trực tiếp trong tiến trình.
